閲覧操作

クリックで選択。通常の選択では視点は変わりません。

左・中ドラッグ：回転 ／ 右ドラッグ・Ctrl＋左ドラッグ：平行移動 ／ ホイール：拡大縮小

キー操作
Home開いたときの視点へ
PageUp / PageDown表示を次へ / 前へ
矢印 / Shift＋矢印回転 / 大きく回転
＋ / −拡大 / 縮小
F / Esc選択対象を局所観察 / 全体観察へ
C世界軸の表示を切替
¥ または ＼ / Shiftを併用定義済み視点を順方向 / 逆方向へ

検索や選択欄の入力中はショートカットを実行しません。表示の再生・停止は「再生」「停止」ボタンを使います。

「接続先へ」は記録された関係を辿る操作、「局所観察」は選択周辺を強調して見る操作です。どちらも作品の内容は変えません。
