# 3DSLアトラスのデザインガイドライン

トップを開いた人が、作品名を見て、その場でモデルに触れられることを優先する。作品一覧では次に開く一作を選べること、資料では読みたい箇所を探せることを優先する。どの画面でも、題・本文・操作は同じ見た目で見分けられるようにする。

## 文字の役割

| 何を示すか | 書体と大きさ | 使う場所 |
| --- | --- | --- |
| ページの題 | 明朝、600、24〜32px相当 | 作品詳細の作品名、「作品一覧」「使い方と資料」「お問い合わせ」、記事の表題 |
| 今触れる作品名 | 明朝、600、24〜28px相当 | トップのモデルのすぐ上。一覧のカードでは18px相当に抑える |
| 章・説明の区切り | ゴシック、600、通常18〜20px相当 | 「ほかの作品」「はじめに読む」など。資料中の見出しは文書の階層に従う |
| 本文・操作・案内 | ゴシック、本文と入力は原則16px相当、案内は14pxを目安 | 操作名や入力値はひと目で読める太さにする。長文の段落は行高1.85を基準にする |
| コード・識別子 | 等幅 | 仕様のコード例、ファイル名・数値を桁で照合する欄 |

明朝は Noto Serif JP を基準に、端末の明朝へ順に切り替える。単体HTMLのツール入口はオフラインでも使えるよう、端末内の書体を使う。ゴシックは欧文の Inter と端末の日本語ゴシックを使う。書体の違いが小さい端末でも、太さ・大きさ・余白で順序を伝える。文字サイズの実装は rem と clamp を使う。

トップの「3DSLアトラス」は16px相当のゴシックにし、二文のコピーをそのそばに置く。直下の作品名がいちばん大きい。カードではサムネイルと題をひとつのリンクにまとめ、その下に「Viewerで大きく開く」など行き先が分かるリンクを置く。

## 色・余白・操作

| 役割 | 基準 | 使い方 |
| --- | --- | --- |
| 背景と面 | 地色 `#0b0f14`。面は白を4%、強い面は6%重ねる | 同じ画面内のグループはまず余白で区切る。カードの角丸は16px相当、入力欄とボタンは12px相当 |
| 文字 | 暗い地に白92%、補助文は白62% | 読む必要がある説明に、無効状態の薄さを流用しない |
| 移動と現在地 | 本文リンクは淡い青 `#a5d8ff` と下線。既存のシアン `#38bdf8` は選択に使う | 現在のナビは枠と下線を加え、支援技術にも現在地を伝える |
| 入力とフォーカス | 入力面 `#151c24`、輪郭 `#687886`。キーボードのフォーカスは `#82c8ff` の2px輪郭 | 入力ラベルは常に見せる。一覧・問い合わせの入力やボタンは高さ44px相当以上を基準にする |
| 実行と状態 | 送信などの主要操作には明るい塗り、解除・前後移動には暗い面 | 操作名は動詞で書く。注意やエラーは、色に加えて理由と次の操作を文で示す |

作品どうし、入力欄どうしの間隔は原則16px相当、別のまとまりには32px相当を目安に取る。見出しとその対象は近くに置く。カードにポインターを重ねたときは面や下線を変え、カードの位置を動かさない。通常文字と背景は4.5対1、操作境界とフォーカスは隣接面に対して3対1以上を確認の目安にする。

## 画面ごとの適用

- **トップ・作品ページ**　作品名とモデルを続けて置く。操作の短いヒントはモデルの近くに、作品の解説・データはその下の開閉欄に置く。
- **一覧**　作品を画像と名前で選べることを優先する。検索・並べ替えは共通の入力部品を使う。テーマごとにカードの色や書体を割り当てない。
- **Docs・Concept・FAQ・ポリシー**　表題は明朝、本文と章見出しはゴシック。長い文章は行幅を絞る。資料カードでは行き先を主に、補足を一段小さくする。
- **問い合わせ・作る／開く**　操作、入力欄、結果の順が分かる配置にする。ツール入口やモデル一覧の単体HTMLにも同じ地色・文字・リンクを使う。
- **Viewer・Modeler・テーマ別HTML**　メニュー・入力・戻る操作はゴシックを基準とする。図の中の文字、線、三軸の色、注目箇所の強調は作品の意味に従う。テーマ固有の比較・断面・数値操作もこの範囲で設計できる。

## 実装と確認

色・書体・角丸の共通値は [site-tokens.css](../../../apps/reconstruction/ssot/shared/site-tokens.css) を変更する。サイトの文字階層とリンクは [global.css](../../../apps/site/src/styles/global.css)、ボタン・入力・ナビは [ui.css](../../../apps/site/src/styles/ui.css)、単体HTMLの入口は [site-entry.css](../../../apps/reconstruction/ssot/shared/site-entry.css) に集約する。ページを追加するときは、まず既存の役割と部品を選ぶ。

公開前には、スマホ幅でトップのモデルにすぐ触れられるか、長い日本語の題が折り返すかを確認する。PCではキーボードで現在地・リンク・入力欄を追う。文字を拡大した場合と外部フォントを読み込めない場合も、操作名や作品名が欠けないことを確かめる。
