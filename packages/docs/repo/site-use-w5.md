## ② 読込前の32 MiB制限

再構築版の共有ガードは既存 `WORK_PACKAGE_MAX_BYTES` を参照する。`file.size` が32 MiBを超える場合は `.text()` / `.arrayBuffer()` を呼ばず、理由と現在の作品が保持されたことを表示する。32 MiBちょうどは既存の読込み・形式検査へ進む。URL取得・従来版アプリ・保存契約・正式スキーマは変更しない。

Modelerの順序は「ファイル選択→容量検査→既存の未適用編集確認→既存の破棄確認→読込み」。容量超過や選択取消で編集を適用せず、作品・dirty・Undo/Redo・未適用編集・保存先を保持する。Viewerは作品と検索・閲覧状態を保持し、入力をリセットして再選択可能にする。

`check:local-file-size` は実際のtoolbarとViewer boot/readModel/browsingControllerを実行し、32 MiB境界と1 byte超過、本文読込0回、状態保持、選択取消、既存確認の順序・拒否を検査する。DOM・OS picker・schema validator・WebGL bridgeは境界の代替であり、ブラウザで32 MiBを描画した試験ではない。

Search Consoleは着手時にGoogleログイン画面まで到達し、未認証。所有権・既存プロパティ種別・インデックス状態・検索実績は未確認であり、数値を0で代用しない。認証後、既存の3dsl.jpプロパティで確認する。不要な新規プロパティ・DNSレコード・権限を追加しない。
