# サイト構成・文書整理 W3

2026-10-10。本人がトップ固定文の制約を解除し、これまでの議論を読者向けの作品解説へ編集する方針を採用した。W0/W1の公開区分、限定サンプル条件、受入済みアプリの契約を維持する。

## 今回の範囲

- トップの重複案内を整理し、作品を見る／作る・開く／使い方／3DSLの狙いへ接続する。
- Docsを利用案内・形式と仕様・技術と開発資料に整理する。既存文書のURL・公開アクセスを維持する。
- 「知識と問い」と「構造と分類」の読解案内を追加する。前者は三読解課題、後者は初期の概念配置スケッチとして説明する。
- 新規モデル・一般理論・三次元の比較効果を認定しない。原資料にない作者・出典・意味対応は補わない。
- 本番の正規URL、サイトマップ、作業画面の検索除外を揃える。Previewのnoindexと本番内のpreview-reconstructionパスは区別する。
- 広告は既定OFFを維持する。文字数・記事数の一律目標や審査合格保証は設けない。
