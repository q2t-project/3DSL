# 作る・保存する・開き直す

この案内は、[新しい制作・閲覧入口](/preview-reconstruction/)の Modeler・Viewer（r0.5）を対象にしています。従来の `/app/modeler` とは保存形式や操作が異なります。

**制作の続きを残すには Modeler で保存し、図を読むには Viewer を使います。自動保存はありません。**

## 1. 作って保存する

1. [Modeler を開く](/preview-reconstruction/modeler_app/index.html)と、「新規」から作品を作れます。保存した作品の続きは「開く…」から始めます。
2. 点や関係を追加し、右側のプロパティで名前・位置などを編集します。「適用」で入力内容を現在の図へ反映します。
3. 「保存」で作品一式を保存します。初回は保存場所と名前を選びます。元のファイルを残したいときや保存先を変えるときは「別名保存」を使います。
4. 続きを作るときは、Modeler の「開く…」で保存したファイルを選びます。`models` フォルダーへの移動は不要です。

保存ダイアログを使えないブラウザでは、ダウンロードによる保存になります。「ダウンロード開始」は保存完了の確認ではありません。受け取ったファイルを開き直し、内容を確認してから制作中のタブを閉じてください。

## 2. 作品一式と図だけの違い

| ファイル | 含まれるものと用途 |
|---|---|
| 新しい作品一式 `.3dsl-work.json` | 「新規」で作る形式です。図、対象・出現・関係、作品に記録した原資料、草稿、変更記録をまとめて保持します。制作の続きにはこちらを使います。 |
| 旧形式の作品一式 `.3dsl-work.json` | 既存の「知識と問い」などの形式です。現在の図、編集前の図、添付された原文・対応記録などを保持します。原記録の意味を、変更後の配置や文字へ自動的に読み替えません。 |
| 図だけの `.3dss.json` | 点・線・文字などの図を保持します。作品一式の原資料や草稿などは含まれません。従来の Viewer で図を読む場合などに使います。 |

新旧の作品一式は拡張子が同じで、内容に応じて読み込まれます。対応する新旧の作品一式と図だけの3DSSは、この入口の Modeler・Viewer で開けます。従来のアプリが作品一式に対応しているとは限りません。

作品一式を開いているときの「図を書き出す」は、図だけの `.3dss.json` を作る操作です。作品一式の保存にはならず、その未保存状態も解消しません。制作の続きを残すファイルと、図だけのファイルを取り違えないでください。

## 3. 未適用の入力を残すとき

**新しい作品一式の「作業入力」**は、未適用のまま作品一式へ保存されます。作成途中の関係も保持されますが、確定した値や接続として図に反映されたことにはなりません。

**旧形式の作品一式や図だけの3DSSで使う従来のプロパティ入力**は、同じ扱いではありません。「未適用の入力あり」と表示され保存が止まる場合は、入力を確認して「適用」するか、不要なら「入力を取消」を選んでください。この入力が残る間は「Viewerで読む」も停止します。

保存や読込みが検査で止まった場合は、表示された対象と理由を確認してください。図だけの書出しで、原資料や未対応の情報まで保存できたことにはなりません。

## 4. Viewerで読む

Modeler 上部の「Viewerで読む」を押すと、**押した時点の作品の写し**を新しいタブに開きます。まだファイルに保存していない編集や、新しい作品一式に保持された草稿も渡されます。この操作はファイル保存ではなく、入力の「適用」も行いません。

その後の編集は自動同期しません。編集は元の Modeler タブで続け、更新した内容を読むときは、もう一度「Viewerで読む」を押してください。「別窓表示」は制作側のプレビューで、作品の情報や草稿を読む画面とは異なります。

保存済みのファイルだけを読む場合は、[Viewer を開き](/preview-reconstruction/contract_viewer/index.html)、「開く…」から選びます。図の書出しは不要です。Viewer は読取専用で、編集・保存は行いません。

## 5. サンプルを使うとき

サイトの作品・サンプルには、各作品の表示条件と[コンテンツ利用方針](/policy/content-usage)が適用されます。Modelerで開けることは、改変や再配布の許諾を意味しません。自作の作品や、利用する操作が許可されたデータで制作してください。
