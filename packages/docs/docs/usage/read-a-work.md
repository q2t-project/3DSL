# 図を読む — 全体から一つの問いへ

**最初から全部を読む必要はありません。** 全体を眺め、一つの問いを決めて、配置や接続を辿ってみてください。3DSLの図は、作品ごとの読み方を確かめながら、全体と部分を往復して読みます。

初めて読む作例には、[「知識と問い」](/docs/works/knowledge-questions)をおすすめします。同じ数値に付いた二つの役割を比べ、回答から根拠資料へ戻る経路を持つ作品です。

## 1. 全体と凡例を見る

まず主題を読み、どのようなまとまりが置かれているかを見ます。細かい言葉を追う前に、作品の解説や凡例で次を確かめてください。

- 何を一つの対象として表しているか。
- 位置・方向・線・色・境界に、どのような意味を与えているか。
- 表示の切替で何が変わるか。何を省略し、何を未確定として残しているか。

同じ描き方でも、作品が違えば意味が変わることがあります。横軸は常に時間、上側は常に重要、といった共通の読み方は仮定しません。

## 2. 一つの問いから辿る

「どれが根拠か」「何と何を比較しているか」「この部分は全体のどこに入るか」など、問いを一つ選びます。

線がある作品では、両端と線に付いた言葉を見て、どの種類の対応かを読みます。線のない作品では、配置のまとまりや対照を見ます。線の交差や文字の近さだけで、つながりを補わないようにしてください。

「知識と問い」なら、同じ数値から「勧告値」「定義への入力」という言葉へ進み、それぞれの活動と根拠資料を比べられます。[「構造と分類」](/docs/works/structure-classification)では、線のない配置を見て、何を対照させようとしているかを考えます。

## 3. 必要な部分を見る

回転・拡大で文字と接続を見ます。新しい作品Viewerでは、図形をクリックして選ぶか、名前・ラベル・IDを検索できます。選択内容は「情報欄」で確認します。画面に見当たらない選択対象は「選択を表示」で確かめられます。

「記録された接続先」に「辿る」がある場合は、その先へ進めます。図形によっては、文字や接続点が別の部品になっています。一つのラベルの選択だけですべての関連情報が出るとは限らないので、線の端や作品の対応説明も見てください。

| 画面で起きていること | 読み方 |
|---|---|
| 表示番号や表示範囲を変えると消える | その範囲では非表示になっています。削除されたことにはなりません。 |
| 記録はあるが、図に配置されていない | 図の外に情報が残っている場合があります。情報欄や作品の説明を確認します。 |
| 線や記録された接続先がない | その表現に接続が記録されていない状態です。対象どうしが無関係だと確定したわけではありません。 |
| 未判定・未確認と書かれている | 否定やゼロへ読み替えず、未決のまま扱います。 |

検索・情報欄・「辿る」は新しい作品Viewerの操作です。Libraryから開く従来のViewerでは、作品の詳細ページと図の凡例を併せて読んでください。

## 4. 全体へ戻って比べる

新しい作品Viewerの「探索を戻る」は前の探索状態へ、「全体へ」は現在の表示の全体へ戻る操作です。「初期位置」は開いたときの視点へ戻します。表示番号を変えていた場合は、作品の案内に従って番号も戻してください。

点・線などを非表示にしていた場合は、「図の表示・設定」で再表示します。全体へ戻る操作と、表示条件を戻す操作は別です。

最後に、最初の問いに答えられたかを確かめます。図に記録されていたことと、見ながら自分が考えた仮説を分けておくと、次に何を調べるかが明確になります。

ファイル形式やアプリの違い、制作・保存の方法は、[作る・保存する・開き直す](/docs/usage/create-save-read)を参照してください。Viewerでの閲覧操作は、作品の編集やファイル保存を行いません。
