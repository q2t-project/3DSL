# はじめての一作品 — 問い・回答・根拠をつなぐ

**「答えは同じ数値なのに、何が違うのか」を読める小さな図を作ります。** 題材は[「知識と問い」](/docs/works/knowledge-questions)の光速度例です。一つの問い、二つの活動、二つの回答、二つの根拠資料に絞り、7つの要素を配置します。

これは3DSLのすべての機能を使う練習ではありません。要素を選ぶ、違いが分かるように置く、関係を記録する、保存して読み直す、という一巡を体験するための制作実例です。PCではこの解説とModelerを別タブで開くと進めやすくなります。

## 1. 何を読み取れる図にするか

1975年のCGPM決議2は、真空中の光速度として **299792458 m/s** を勧告しました。1983年のCGPM決議1は同じ値を引き継ぎ、光が一定時間に進む距離によってメートルを定義しました。ここでは、数値の一致と、その数値が果たす役割の違いを比べます。決議の参照先は末尾にあります。

この図で答えたい問いを、二つに固定します。

- 同じ数値が、どの活動の回答として使われているか。
- それぞれの回答から、どの資料へ戻ればよいか。

数値が同じという理由だけで二つの回答を一つにまとめると、「勧告値」と「定義への入力」の違いが見えにくくなります。そこで回答を別々の要素として作り、同じ高さに並べて比較します。これは光の速さがこの間に変化した、という図ではありません。

## 2. 新規から7つの要素を置く

Modelerの「新規」を押します。編集中の作品がある場合は、先に保存してください。

1. 「＋点 (P)」を押すと、新しい対象が追加されて選択されます。
2. 右側の「共有名称」に、下の表の名前を入れます。
3. 「この出現の位置 x, y, z」に、表の3数値を半角カンマ区切りで入れます。
4. 「適用」を押します。次の対象も同じ手順で追加します。

| 要素 | 共有名称に入れる文字 | 位置 x, y, z |
|---|---|---|
| 問い | Q SIにおける真空中の光速度の値 | `0, 30, 0` |
| 活動1 | L75 1975年：値を勧告する | `-28, 10, 0` |
| 活動2 | L83 1983年：メートルの定義を決める | `28, 10, 0` |
| 回答1 | A75 299792458 m/s：不確かさを伴う勧告値 | `-28, -12, 0` |
| 回答2 | A83 299792458 m/s：定義への入力 | `28, -12, 0` |
| 資料1 | S75 1975年CGPM決議2：勧告部分 | `-28, -34, 0` |
| 資料2 | S83 1983年CGPM決議1：定義と1975年値への言及 | `28, -34, 0` |

Q・L75などは、選択時に見つけやすくする短い目印です。アプリが内部で割り当てるIDを入力する必要はありません。「この出現のラベル」は「共有名称を表示」のままにします。

今回は**XY平面に並べ、Zはすべて0**にしています。Xの負側と正側に二つの経路、Yの大きい側から問い・活動・回答・資料を置きます。画面上の上下左右は、見る方向によって変わります。「全体へ」で収めてから、図の空いている場所をドラッグして、二列を比較しやすい向きで見てください。

座標は文字を分けて置くための値です。距離は時間の差や重要度、光速度の大小を表しません。三次元で表示できても、今回の問いに不要な奥行きは加えません。表示所属も初期値の0のままで足ります。

## 3. 六つの関係を作る

「＋線 (L)」を押し、右側の「作成途中の関係」を使います。

1. 「新しい関係の名称」に、下表の名称を入れます。
2. 「参加枠1の対象・出現」「参加枠2の対象・出現」で、下表の要素を選びます。選択肢の名前の末尾にはIDも表示されます。
3. 「参加枠1の役割」「参加枠2の役割」に、下表の役割を入れます。
4. 「この関係を作成」を押します。残りの5件も同様に作ります。

| 関係の名称 | 参加枠1 | 枠1の役割 | 参加枠2 | 枠2の役割 |
|---|---|---|---|---|
| 問いを扱う | Q | 問い | L75 | 活動 |
| 問いを扱う | Q | 問い | L83 | 活動 |
| 回答 | L75 | 活動 | A75 | 回答 |
| 回答 | L83 | 活動 | A83 | 回答 |
| 根拠を参照 | A75 | 回答 | S75 | 資料 |
| 根拠を参照 | A83 | 回答 | S83 | 資料 |

画面では、一つの関係に名称の付いた点と、参加する二要素へ伸びる線が作られます。**一つの関係が一本の線とは限りません。** この完成例は7対象・6関係で、図を構成する点や線の部品数とは異なります。

「根拠を参照」は、回答から資料へ読み戻るための名前です。「回答が資料を生んだ」という因果を表していません。線の向きだけに頼らず、関係名と参加枠の役割で対応を記録します。

## 4. 読み直して、配置と説明を直す

「全体へ」を押し、次の二経路を辿ります。

| 経路 | 読み取れること |
|---|---|
| Q → L75 → A75 → S75 | 値を勧告する活動に、不確かさを伴う勧告値が対応し、1975年の決議へ戻れる |
| Q → L83 → A83 → S83 | メートルの定義を決める活動に、定義へ用いる値が対応し、1983年の決議へ戻れる |

二つの数値だけが目に入って役割の違いを見落とすなら、回答の文字と活動の名前を読み比べます。文字が重なる場合は、対象を選んで「この出現の位置」を調整し、「適用」します。対象は動かさず文字だけをずらす場合は、「ラベル位置・表示所属」内の「ラベル位置差 x, y, z」を変えます。

関係を作った後に対象を移動すると、接続先は同じ対象のまま保たれます。ただし関係名の点まで同じ並びに自動整列されるわけではありません。初回は表の位置で作り、変更前後を見比べるのが確実です。

新規作成した対象の情報には「内容の状態：未判定」と表示されます。これはアプリが追加する初期状態です。名前に史実を書いたことや、形式の検査に通ったことから、自動的に史実の確認済みへ変わるわけではありません。

## 5. 保存して開き直し、Viewerで読む

1. 「別名保存…」で、例えば `my_first_work.3dsl-work.json` として保存します。「図を書き出す」ではなく、作品一式を保存します。
2. 「開く…」でそのファイルを開き直します。7つの名前と、六つの関係の接続を確かめてください。
3. 「Viewerで読む」を押します。新しいタブに、押した時点の作品の写しが開きます。
4. Viewerの検索に `A75` を入れ、回答を選びます。「情報欄」の記録された接続先から、活動や根拠資料へ辿れるか確認します。`A83`でも同じように比べます。

ダウンロードによる保存では、受け取ったファイルがあることと、そのファイルを開き直せることまで確認してください。自動保存はありません。Viewerで読む操作も保存にはなりません。詳しくは[作る・保存する・開き直す](/docs/usage/create-save-read)を参照してください。

完成例には出典と読み方のメモを添付しています。「新規」から上の操作で作るのは、図の要素・配置・関係です。添付メモまで同じにしたい場合は完成例を開き、別名保存して練習できます。

## 今回、省いたもの

元作品には、問い・活動・回答の一般構成や、整列と分類を読む経路もあります。この練習ではそれらを省き、光速度の二記録だけに絞りました。資料全体と参照箇所も一つの表示へまとめ、名前の中で「勧告部分」などを明記しています。

二つの決議の継承関係、U/E/Jの区分、不確かさの詳しい数値・算定、現在のSIの定義までは表していません。1983年の定義は、2019年に効力を持つ新しい定義へ移行しています。ここで扱うのは二つの歴史的記録の比較です。

平面の二列配置だけでも、この小さな比較はできます。奥行きの効用や、あらゆる知識に通用する分類を、この一例で示したことにはしません。次に自分の題材へ移るときも、まず「何を比べ、どこへ戻って確かめたいか」を一つ決め、必要な区別だけを増やしてみてください。
