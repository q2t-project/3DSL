# 作品の更新・訂正について

3DSLのアトラスと解説は、調査・検証と表現の改善に応じて継続的に改訂します。対象や論点を増やすことも、分類や説明の組み立てを見直すこともあります。誤りが見つかった場合は、内容を確かめて訂正します。

## 版と日付を見る

作品を読み返すときは、作品情報の版と改訂日を確認してください。「作品の版」は図のデータの版です。3DSSという保存形式の版や、表示するViewerの版とは異なります。

作品ページの「3DSS原本の版」は、配布する図のデータを指します。専用の読解ガイドが別の版を表示する場合は、原本の版と分けて確認してください。引用するときは、実際に参照したガイドまたは原本の版を記します。

作品ページの公開日・更新日は、サイトへの掲載や掲載内容の更新を示します。解説だけを更新した場合は、図の作品版や改訂日が変わらないこともあります。

法令や統計などを扱う作品では、出典の基準日と確認した範囲も見てください。図の改訂日が新しくても、参照する資料のすべてをその日に確認したことを意味しません。

## 以前と内容が違うとき

主要な変更は、作品の解説にある「更新履歴」で案内します。解説が折りたたまれている作品では、解説を開いて確認してください。論点の追加、資料の変化への対応、作者による整理の見直し、過去の誤りの訂正を区別して記録します。3DSLでは、概念の配置や矢印の向きが変わることで、図から読み取れる意味も変わる場合があります。

以前の版から得た理解に大きく影響する訂正は、作品情報や解説の冒頭などにも案内を置きます。どの版のどこを訂正したか、修正後の内容と影響する範囲を確認できます。

この運用は2026年11月22日以降の公開・改訂から適用し、既存作品の履歴は順次整えます。それ以前の改訂は、確認できる記録に限って掲載します。履歴が掲載されていない期間について、変更がなかったことを保証するものではありません。

## 保存したファイルや画像を使うとき

手元に保存したHTML・3DSS・画像は、サイトの改訂に合わせて自動では更新されません。ファイルの作品情報や案内先から作品ページへ戻り、現在の版と重要な訂正を確認してください。案内が見当たらない場合は、[作品一覧](/library/)から作品名を探せます。

紹介・引用の際は、作品名とURLに加えて、確認できる作品の版や改訂日、閲覧日を添えると、どの内容を参照したかが伝わります。保存版へのリンクを掲載している作品では、その版を指定できます。全作品の全旧版を公開しているわけではありません。利用できる範囲は、[各作品の表示条件と共通の利用条件](/policy/content-usage/)をご確認ください。

誤りや分かりにくい箇所に気づいた場合は、[お問い合わせ](/contact/)から、作品名・URL・分かる範囲の版と該当箇所をお知らせください。
