# 3DSL Viewerの使い方

## 作品を読む

[3DSL Viewerを開く](/app/viewer/)。作品へのリンクから開くと、その作品が表示される。手元の作品は「開く」から選ぶ。作品一式（.3dsl-work.json）と図（.3dss.json）の両方を読み取る。図だけを開いたときは、端点に参照が記録されている線を接続としてたどれる。

## スマホでの操作

通常は画面の大半を図に使う。1本指で回転し、2本指で移動・拡大縮小できる。端にある小さな三軸は現在の向きを示す。タップするとギズモが広がり、次の操作で視点を変えられる。ギズモを使った直後も、図を1本指でドラッグするとそのまま回転できる。2本指なら移動・拡大縮小できる。図をタップするだけなら選択を保ってギズモを閉じる。

図上で要素を選ぶと、その名前と使える操作が出る。「探す」で名前やIDを検索し、候補を選ぶと図に戻る。情報欄で接続先に進み、「探索を戻る」で前の対象へ戻る。情報欄を開閉しても、見ていた角度や倍率を保つ。

メニューには作品を開く操作、表示設定、ヘルプがある。複数フレームの作品ではフレーム移動・再生を使える。読み取りの注意は件数から全文を開ける。読込に失敗した場合は理由を表示し、再びファイルを選べる。

## 開く場所と表示形態

通常閲覧と共有の正規入口は `/app/viewer/`。作品ページの小さな埋込は、同じ読み取り・描画処理で図を表示する。以前配布したViewerのURLからも作品指定を引き継ぐ。Modelerの「Viewerで読む」は、押した時点の作品の写しを別のタブで開く。Viewerでの操作は元の作品を書き換えない。
