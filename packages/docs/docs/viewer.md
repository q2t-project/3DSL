# 3DSL Viewerの使い方

## 作品を読む

[3DSL Viewerを開く](/app/viewer/)。作品へのリンクから開くと、その作品が表示される。手元の作品は「開く」から選ぶ。作品一式（.3dsl-work.json）と図（.3dss.json）の両方を読み取る。図だけを開いたときは、端点に参照が記録されている線を接続としてたどれる。

## スマホでの操作

通常は画面の大半を図に使う。1本指で回転し、2本指で移動・拡大縮小できる。端にある小さな三軸は現在の向きを示す。タップするとギズモが広がり、次の操作で視点を変えられる。ギズモを使った直後も、図を1本指でドラッグするとそのまま回転できる。2本指なら移動・拡大縮小できる。図をタップするだけなら選択を保ってギズモを閉じる。

図上で要素を選ぶと、その名前と使える操作が出る。「探す」で名前やIDを検索し、候補を選ぶと図に戻る。情報欄で接続先に進み、「探索を戻る」で前の対象へ戻る。情報欄を開閉しても、見ていた角度や倍率を保つ。

メニューには作品を開く操作、表示設定、ヘルプがある。読み取りの注意は件数から全文を開ける。読込に失敗した場合は理由を表示し、再びファイルを選べる。

解説やLibraryから開いた場合は「元のページへ戻る」で、その入口へ戻れる。スマホでは「メニュー」、PCでは画面上部に表示する。外部サイトや認証情報を含む戻り先は表示しない。別タブで図を開いた場合は元の解説タブも残る。

### 図を表示できないとき

読込・表示に失敗した場合は、PCとスマホの両方で理由と案内を表示する。「元のページへ戻る」があれば、開く前の同じサイト内のページへ戻れる。「このURLを再読み込み」は、まだ作品を開けていないURL読込時に使える。前の作品記録を保持している場合やModelerから受け取った写しには、この再読み込みを出さない。

公開サイトでは[図が表示されないときの案内](/docs/usage/read-a-work/#without-3d)と[文章と表で読む例](/docs/usage/first-work/)へ進める。JavaScriptが無効な場合も、この二つの解説へのリンクを表示する。単独配布のViewerでは同梱の作品入口へ案内する。

### 「表示」の番号を切り替える

複数のフレームがある作品では、「メニュー」を開き、パネル内の「表示」の行までスクロールする。数字の欄をタップして見たい番号を選ぶ。「前」「次」なら一つずつ切り替わり、「再生」で順に表示できる。「閉じる」を押すと、選んだフレームの図を広く見られる。

## 開く場所と表示形態

通常閲覧と共有の正規入口は `/app/viewer/`。作品ページの小さな埋込は、同じ読み取り・描画処理で図を表示する。以前配布したViewerのURLからも作品指定を引き継ぐ。Modelerの「Viewerで読む」は、押した時点の作品の写しを別のタブで開く。Viewerでの操作は元の作品を書き換えない。
