# 3DSLとは

3DSL（Three-Dimensional Structural Language）は、概念や対象を三次元空間に配置し、関係を表し、考えるための試みです。全体を見渡し、必要な部分へ寄り、図と文章を行き来して、何をどう捉えたのかを確かめます。

## 表現・アプリ・形式の役割

| 名前 | 役割 |
|---|---|
| 3DSL | 配置と接続を使って、対象や関係を表現し、考えるための試み。 |
| Viewer | 対応する作品を開き、視点を動かし、要素や接続を読むアプリ。閲覧操作は作品を編集・保存しません。 |
| Modeler | 点や関係を編集し、作品を端末へ保存して制作を続けるアプリ。 |
| 3DSS | 点・線・文字などの図をJSONで記録するデータ形式。 |
| 作品一式 `.3dsl-work.json` | 図に加え、原資料や草稿などの制作情報を保持する形式。含まれる情報は新旧の形式で異なります。 |

研究では、対象の捉え方、関係、軸や配置の意味を検討しています。公開作品には制作時点の試案も含まれます。個別作品の配置や解釈を、そのまま共通仕様として扱うことはしません。考え方は[3DSLの狙い](/concept/)で、各作品の意味や出典は作品の解説で確認できます。

3DSSの仕様は図のデータに何を記録できるかを定めます。形式に適合することと、図が表す主張に根拠があることは、別々に確かめます。

## 目的から始める

- **初めて読む**：[「知識と問い」の解説](/docs/works/knowledge-questions/)から図を開き、一つの問いとその根拠を辿ります。[図を読む案内](/docs/usage/read-a-work/)では見方と操作を説明しています。
- **保存した作品を読む**：[Viewer](/app/viewer/)の「開く」からファイルを選びます。公開作品は[Library](/library/)から探せます。
- **作る・続きを編集する**：[制作・閲覧入口](/preview-reconstruction/)からModelerを開きます。[制作と保存の案内](/docs/usage/create-save-read/)で、形式の違いと再開手順を確認できます。
- **形式を調べる**：[3DSSの概要](/docs/overview/what-is-3dss/)、[公開仕様](/docs/spec/latest/)、[JSON Schema](/docs/schema/latest/)へ進みます。
