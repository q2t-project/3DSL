# 3DSSとは

3DSS（Three-Dimensional Structural Schema）は、3DSLが扱う図をJSONで記録するデータ形式です。図だけのファイルには `.3dss.json` という拡張子を使います。

| 項目 | 記録するもの |
|---|---|
| `points` | 点と、その位置・文字・表示など。 |
| `lines` | 線と、その端点・キャプション・表示など。 |
| `aux` | 補助要素。 |
| `document_meta` | 図のタイトル、識別子、版などの情報。 |

各項目の必須条件や記述方法は仕様・スキーマで確認してください。この表は構成の概要です。

## 図だけと作品一式の違い

Viewerは、対応する3DSSと作品一式 `.3dsl-work.json` を開けます。3DSSに記録するのは図です。作品一式が保持する原資料や草稿などの制作情報は、図だけの書出しには含まれません。

制作の続きを残す場合は、Modelerで作品一式を保存します。作品一式には新旧の形式があるため、[制作と保存の案内](/docs/usage/create-save-read/)で保持範囲を確認してください。Viewerで図を見る操作は、ファイル保存にはなりません。

## 形式を検査する

JSON Schema（`3DSS.schema.json`）は、型や必須項目など、ファイルの形式上の条件を検査するための定義です。図が表す分類・因果関係・出典の正しさを、この検査だけで判断することはできません。線や配置が何を意味するかは、各作品の解説で確認します。

現在の公開版は **v1.1.4** です。[公開仕様](/docs/spec/latest/)と[スキーマの案内](/docs/schema/latest/)から参照できます。版を固定して記録する場合は、[v1.1.4仕様](/docs/spec/v1.1.4/)と[v1.1.4スキーマ](/docs/schema/v1.1.4/)を使ってください。
