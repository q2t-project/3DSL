## 見本、旧仕様、生成元

- Viewer・ConceptのExcel入出力由来の見本には、当該パスの初出と更新のGit記録を使って日時（2026年1月10日、1月28日）を補った。既定の文字面を明示し、未知属性を試す `__unknown_test` は配布用の2見本から取り除いた。当時のExcel入出力試験データは凍結済みの `xls2json` にある。
- 現行の回帰用見本は v2.0.0 に切り替えた。旧版の書式、異なるURI、非正規の旧文字姿勢を検出する例では、元の旧版URIや不正URIを使う。
