# HG-V1 文字と色の凡例の判断

2026-10-30 JST。P0〜P2の成果。次工程は、ここで採る表現の意味に基づくViewer／Modeler本体への実装。

[回転する見本を開く](https://b0fea878.3dsl.pages.dev/preview-reconstruction/legend_lab/)。検証したコードは `cbc830ef79c336e2604364747e42c80363f0be50`、作業PRは [#71](https://github.com/q2t-project/3DSL/pull/71)。

## 判断する内容

小さな食事関係を回転して、次の対応が意図した読み方になっているか確認する。

| 対応 | この見本の表現 |
|---|---|
| 状態を切り出して読む | 家の米・ご飯はXZ面、横書き |
| 時間を通じた維持・配分を数量側から読む | 保管・取り分けはYZ面、縦書き |
| 時間を通じた性質変化を読む | 炊飯はXY面、縦書き |
| 役割の型として読む | 調理役はXZ面、横書き。「注：役割の型」で状態と区別 |
| 作者の説明を読む | 「注：」を付け、明朝体を併用 |
| 関係系列を追う | 米の経路、担当、エネルギーを線の三色で補助。関係語と矢印も残す |
| 観察スコープを読み分ける | 主要語16、局所の語・注記8、線の関係語4。数量の大小ではない |

この見本の位置は説明配置であり、米の主経路の+Yに限って工程順序を表す。q・Q・tの全座標へ意味を割り当てた完成モデルではない。XYを時間なしの面とする旧試作の対応は採っていない。

## 見る順序

1. 初期表示の「4 ＋色」で、保管・家の米・炊飯・調理役を確認する。
2. 「比較」を「1 面とサイズ」から「2 ＋縦書き」「3 ＋書体」「4 ＋色」へ変え、何が読みやすくなるか比べる。位置・姿勢・サイズ・接続は変わらない。
3. 「保管を見る」で保管前・保管・家の米へ寄り、「炊飯を見る」で炊飯と関与する語を読む視点へ切り替える。後者は関係全体を収めるので、文字が一律に大きくなるとは限らない。「初期」で全体へ戻る。
4. 「色なし」「単一書体」を有効にし、関係語と「注：」から同じ区別をたどれるか見る。
5. 文字を選択し、モデルを見ながら下部の説明・凡例を読む。局所の語8や関係語4は必要に応じて拡大する。書体差を比べる際は注記を選んで「選択へ」で寄る。初期全体で全サイズが常に読めることを合格条件にはしない。

## 返してほしい判断

- A：この対応を候補として採用し、本体への実装へ進む。
- B：面・縦横などの意味対応を修正する。違和感のある語と、どう読みたいかを指定する。
- C：特定の手段を保留する。例えば書体差だけを保留し、面・縦横・サイズ・色を先に進める。

「保管と炊飯の面・縦横を分ける意味が分かるか」「状態と役割を同じ面に置き、注記で区別する方針でよいか」「書体と色が読解の補助になるか」が判断の中心。色コードや内部フィールド名の個別承認は求めない。

## 技術面で準備できたもの

- v2.0.0候補スキーマ。0.125〜256の倍々刻み、点と線の縦横・書体・太さ・文字色、作品の凡例と複数参照を記録する。
- 旧版で許される13・6・10を無断変換せず、新版へURIだけを替えた文書は拒否する検査。
- 旧実validatorのvalid11件・invalid14件を保つ回帰検査。見本込みの候補検査232件。
- 61元ファイル・7,479サイズの監査。公開Library9作品の3,197サイズは倍々規則に適合。未適合の原値と移行候補は記録し、丸めは未実施。
- 固定した文字面、日本語縦組、実フォント二系統、比較切替、選択、回転を行う専用見本。フォントは同梱し、外部CDNへの接続は不要。

見本は候補の意味を判断するための専用表示である。既存Viewerの新旧版切替とModelerの編集・保存対応はP3に残る。現行Modelerに候補データを読み込んで保存する手順はまだ提供しない。現行の未知属性の扱いでは新しい凡例等を失うため、その保持をP3の必須条件にしている。

公開・凍結・再構築版の現行スキーマを置き換えていない。候補の配布先はcandidatesに分離し、既存食事モデルもそのまま保持する。

## 表示検証の範囲

最終候補は [CI 41001642648](https://github.com/q2t-project/3DSL/actions/runs/41001642648) でビルド、旧Viewer回帰、新候補検査232件、360／390／1280pxの見本操作に合格した。実ラベルと形状の頂点を投影してカメラを合わせ、比較段階ごとの内容・姿勢・サイズ・接続の保持、実フォントと縦組、文字選択、回転、関係別の視点、図と情報の併存を検査した。Previewの配布も成功している。

各比較段階、色なし・単一書体、関係別の視点の画像と計測値をCIの `visual-grammar-*` 成果物へ記録した。スマホ・デスクトップの画像を確認し、保管の主要語と接続語の接触を解消した。スマホの全体図では関係語4と注記8の書体差は判別しにくく、局所拡大が必要である。保管へ寄る際に周辺の語が画面外へ出ても、データからは消さずに保持する。

文字の画面上の外接矩形や単色背景に対する指定色のコントラストは検査できるが、読者が意味を理解したことの証明ではない。実Androidでの読解受入は後段HG-V2で行う。

色覚対応の代償として、関係語・注記が占める面積と混雑、細部へ拡大する操作、作者の色や書体の印象が変わることを評価に残す。機械検査の合格を、全員が識別できることやサイト全体のアクセシビリティ適合へ読み替えない。
