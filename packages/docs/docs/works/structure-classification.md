# 構造と分類 — 概念の置き方を比べる

「構造」「分類」「状態」「概念」を、どのような位置関係で考えられるでしょうか。この作品は、対象の存在と、それを捉える認識という観点から、関連する言葉を空間に置いた**初期の配置試案**です。

33点・0線で構成されています。接続線を辿る図とは異なり、言葉の並び・まとまり・向き・表示の切替を見比べる作品です。

## 最初の問い

> 「存在」と「認識」を離して置くと、「状態」と「分類」の違いをどのように眺められるでしょうか。

ここでは、用語の定義をすべて確定するよりも先に、何を対照させ、何を近くに置こうとした図なのかを読みます。

## 配置から読めること

この作品では、視点を変えて言葉の位置や向きを比較できます。一つの文章を順に読む場合と違い、いくつかの語を同時に見ながら、何と何を対照させるかを考えられます。

ただし、線がないため、因果・包含・同一性などの関係の種類は明記されていません。近い場所にあることだけで「同じ意味」、離れていることだけで「対立」とは決まりません。距離を重要度や類似度の数値として読む規約も示されていません。

同じ位置に複数の文字が置かれ、文字の向きや揃え方が異なる箇所もあります。見えにくい語があれば、その語が存在しないとは考えず、表示番号と視点を確認してください。表示の切替を、歴史的な順序や概念の発生順序として読む根拠はありません。

## 観察と解釈を分けて記録する

例えば、表示3で「状態」と「概念」を見つけたら、次の三段階を分けてください。

| 段階 | 記録すること |
|---|---|
| 図で確かめる | 二つの語が表示されているか。位置・向き・周囲の語はどう違うか |
| 読者が考える | 対象の状態を見ることと、対象を概念で捉えることを、どう対照できるか |
| 図だけでは決めない | 一方が他方を生む、包含する、定義する、という関係まで成立するか |

二段目はこの図を使った問いの立て方であり、配置から確定した命題ではありません。三段目を主張するには、関係の種類や根拠を追加して検討する必要があります。

読み終えたときの到達点は、**一組の語の位置関係を説明し、そこから自分が考えた解釈と、図にはまだ記録されていない関係を分けて言えること**です。線で関係を記録した場合との違いは、[「知識と問い」の読解](/docs/works/knowledge-questions/)と比べられます。

## この試案の範囲

これは構造や分類を考えるための概念スケッチで、完成した分類表や、哲学理論全体の再構成ではありません。「分・類」と「共通化・差異化」の対応、各軸の定義などは、配置だけから一意に決められません。

既存の語と配置を見比べることを、この解説の範囲にしています。どの配置が理解に役立つかは、読む目的に応じて確かめていく必要があります。
