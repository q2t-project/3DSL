# 知識と問い — 回答から根拠へ辿る

**同じ答えでも、何のための答えかが変わることがあります。** この作品は、問い・活動・回答・規準・資料のつながりを、全体図と二つの具体例で表しています。回答だけを取り出さず、それを支える活動と資料へ戻って読むための図です。

<a href="/preview-reconstruction/contract_viewer/index.html?model=/preview-reconstruction/models/knowledge_questions.3dsl-work.json" target="_blank" rel="noopener">作品を再構築版Viewerで開く（別タブ）</a> ／ [作る・開く](/preview-reconstruction/)

図は新しいタブで開きます。この解説を残し、タブを切り替えながら読めます。

## 最初の問い

> 同じ「299792458 m/s」が二つ並んでいます。それぞれ、何のために使われている数値でしょうか。

最初はこの違いを読むだけで構いません。その後、資料や分類へ辿る別の経路を見てください。

## 三つの表示を読む

Viewer上部の「表示」にある数値欄で、**0・1・2**を選びます。「前」「次」でも切り替えられます。図を拡大しすぎた場合は「全体へ」、視点を戻したい場合は「初期位置」を使います。

| 表示 | 見る場所 | 読み取ること |
|---|---|---|
| 0：全体 | 上段の一般構成と、下段の光速度・整列の例 | 問い、論点、回答、資料がどうつながり、二つの例が全体のどこに位置するか |
| 1：光速度 | 1975年と1983年の二つの記録 | 同じ数値に付いた「不確かさを伴う勧告値」と「単位を定める入力」の違い |
| 2：整列 | 「D02 整列」から資料・分類へ続く経路 | 何についての論点か、資料のどの部分に対応するか、分類が何に付与されたか |

### 表示1：数値と役割を分ける

1975年側の数値から「値を勧告する」、1983年側から「メートルの定義を決める」へ辿り、それぞれの根拠資料を見ます。作品では同じ数値を並べつつ、回答の役割を別々に記しています。

ここで比べているのは、数値の大小だけではありません。「どの活動で、どの資料に支えられた回答なのか」を含めて比較します。図の二つの記録から、光そのものの速さがこの間に変わったとは読みません。

### 表示2：分類の付与先を確かめる

「D02 整列」から「B02 第6〜8章」、その章を収める資料全体、東京都立図書館の付与記録、「NDC10 007.64」の順に目で辿ります。逆に戻ると、分類項目から元の論点までの間に、何を介しているかが分かります。

**この図で分類が付いているのは資料全体です。** 「整列」という論点や一つの章に直接付与した分類として読まないことが、この経路の要点です。

読み終えたら表示を0へ戻し、「全体へ」を押して、いま見た経路の位置を確かめてください。図形を選ぶと「情報欄」に記録が表示されます。記録された接続先を操作で辿った場合は、「探索を戻る」で前の探索状態へ戻れます。

## 読み終わったときの確認

図を閉じる前に、次の二点を図中の記録で確かめてください。

| 問い | この作品で確認する答え | 読み違えないこと |
|---|---|---|
| 同じ数値は同じ役割か | 1975年側は勧告値、1983年側は定義に用いる値として、活動・資料と分けて記録されている | 数値が一致することと、回答の役割が一致することは別 |
| 整列の分類は何に付くか | 章や論点ではなく、章を収める資料全体への付与記録を介している | 章や論点へ分類を直接付けたと読み替えない |

答えが見つからない場合は、表示1または2へ戻り、数値や分類項目だけでなく、その手前にある活動・資料の記録を確認します。図の読み方に加え、根拠そのものを確かめたい場合は末尾の原資料へ進んでください。

## この作品の読み方の規約

- 線の「回答」「根拠」「収録元」などの言葉が、対応の種類を示します。破線の「この例」は、一般構成と具体例の対応です。
- 表示0・1・2は見る範囲の切替です。時間の進行ではありません。座標値・距離・角度・奥行きは、数量や重要度、年代の間隔を表しません。
- Uは「理解・知識」、Eは「実現・維持・改善」、Jは「規準・採用根拠」です。付記の「主・支・外・?」は区分で、数値の三軸ではありません。「?」は未判定を表し、否定やゼロとは異なります。
- この作品は、図と編集前の原記録を持つ旧形式の作品一式です。図のラベルや配置を変更しても、原記録の意味が自動的に書き換わるわけではありません。

## この図に含めていないこと

収録範囲は一般構成と二つの読解経路です。あらゆる知識を配置した地図ではありません。上段に分類への経路があることから、下段のすべての資料に分類付与が確認済みとは読めません。

整列の資料との対応は目次に基づき、章全文の同一性は未確認です。光速度の資料に対する分類付与も、この図では未確認のままです。この解説では、元の図にない書名や出典情報を補っていません。
